# 若松町内会ホームページ ご利用の手引き（一般住民・会員向け）

福山市若松町の皆さんへ。  
町内会ホームページは、スマートフォンやパソコンから、いつでも簡単にご利用いただけます。

---

## 1. どなたでも見られる情報（ログイン不要）

- **最新のお知らせ・緊急情報**: トップページで、町内の重要なお知らせや台風・大雨時の緊急情報を確認できます。
- **行事予定（カレンダー）**: 月ごとの行事、清掃活動、夏祭り、防災訓練の日程を確認できます。
- **地域マップ・お散歩コース**: 若松集会所、避難場所、AEDの位置や、おすすめのお散歩コース（距離・所要時間）を確認できます。
- **防災情報**: 避難所一覧、災害時の連絡手順、備蓄品リストを確認できます。
- **回覧板**: 最新の回覧板をスマートフォンでいつでも閲覧できます。
- **写真アルバム**: 町内会活動の楽しい写真を閲覧できます。

---

## 2. 備品予約の使い方（テント・長机・草刈機など）

町内会の備品（大型テント、長机、パイプ椅子、発電機、草刈機）を借りたいときは、スマートフォンから空き状況を確認して予約できます。

1. メニューから「**備品予約**」を押します。
2. 借りたい備品を選びます。
3. **カレンダー（空き状況）**が表示されます。
   - 🟩 **緑色（残あり）**: 借りられます。
   - 🟥 **赤色（満）**: すでに他の方が借りています。
4. カレンダーの空いている日付をタップします。
   - 1回目のタップで「**貸出日**」、2回目のタップで「**返納日**」が決まります。
5. 「**この備品を予約リストへ追加**」を押します（複数種類の備品をまとめて予約できます）。
6. お名前、電話番号、組班名（例: 2組3班）を入力し、「**予約を登録**」を押します。
7. 予約が完了すると画面にメッセージが表示されます。役員が確認後、貸出確定となります。

---

## 3. ご意見・ご相談の投稿方法

「街灯が切れている」「側溝の掃除について相談したい」など、町内会へのご意見や相談を投稿できます。

1. メニューから「**情報交換**」を押します。
2. 投稿フォームにお名前（匿名でもOK）、カテゴリ、内容を入力します。
   - **全体公開**: 町内の皆さんと共有して情報交換したいとき
   - **役員への相談（非公開）**: 役員に直接相談したいとき（他の方には公開されません）
3. 現場の写真がある場合は、写真を添付することもできます。
4. 「**送信する**」を押します。
5. 役員が確認し、対応状況や返答が画面に表示されます。

---

## 4. 活動写真の投稿方法

夏祭りや清掃活動、子供会の写真など、町内の活動写真をアルバムに投稿できます。

1. メニューから「**写真アルバム**」を押します。
2. 投稿フォームで、お名前とコメントを入力し、写真を選択します。
3. スマートフォンで撮影した大きな写真も、**自動的に適切な大きさに縮小**されて送信されますので、通信量を気にせず安心して投稿できます。
4. 送信後、役員が内容を確認（プライバシー・肖像権の確認）した上で、アルバムに公開されます。

## 5. ご利用にあたってのお願い

- 写真やお名前を投稿する際は、他の方のプライバシーや肖像権にご配慮をお願いいたします。
- 操作で分からないことがありましたら、お近くの町内会役員までお気軽にお尋ねください。
