# 若松町内会ホームページ 管理者操作説明書（役員向け）

本説明書は、町内会役員（管理者）がホームページを日常運用するための手順書です。  
難しいプログラミング操作は一切不要で、ブラウザから簡単に登録・承認・確認が行えます。

---

## 1. 管理ページへのログイン方法

1. ホームページのメニューから「**管理ページ**」を押します。
2. **ログイン画面**が表示されます。
   - **ユーザーID**: お持ちの役員メールアドレス（または指定のID）を入力します。
   - **PIN（パスワード）**: 決められた4桁の数字（またはパスワード）を入力します。
3. 「**ログイン**」ボタンを押します。
4. ログインに成功すると、「ログイン中: ○○（役員）」と表示され、管理用パネルが展開されます。

> [!NOTE]
> ブラウザを閉じると自動的にログアウトされます。安全のため、共用パソコンでは作業終了後にブラウザを閉じてください。

---

## 2. 日常の管理業務手順

### 2-1. 行事カレンダーへの予定追加
1. 管理ページの「**行事管理**」セクションを開きます。
2. 「**町内会カレンダー予定を管理者登録**」フォームに入力します。
   - **イベント名**: 例「秋の町内一斉清掃」「役員会」
   - **開始日時 / 終了日時**: 日時を選択（終日の場合は「終日予定として登録」にチェック）
   - **場所**: 例「若松集会所」
   - **補足説明**: 持ち物や集合場所など
3. 「**町内会カレンダーへ登録**」ボタンを押します。
4. ホームページの「行事予定」を開くと、即座にカレンダーへ反映されます。

### 2-2. 定例行事の年間一括登録（月1回の定例会など）
毎月第1日曜の清掃活動など、定期的に繰り返す予定を1年分（12か月分）まとめて登録できます。
1. 「**定例行事を年間一括登録（12か月分）**」フォームを開きます。
2. 行事名、場所、毎月の週（第1週など）、曜日（日曜など）、開始時刻・終了時刻を入力します。
3. 「**年間一括登録（12件）**」ボタンを押すと、今月から1年分の予定が一括生成されます。

### 2-3. 会員企画イベントの承認・公開
会員がホームページから企画したイベント（スマホ茶話会、手芸クラブなど）は、管理者が承認するまで一般公開されません。
1. 管理ページの「**会員企画イベント一覧**」を確認します。
2. 内容や参加人数を確認し、「**公開を承認**」ボタンを押します。
3. 承認されたイベントは、コミニティカレンダーおよび行事予定に公開されます。

### 2-4. 備品の貸出・返納確認
会員からスマートフォンの備品予約フォームを通じて予約申請が届きます。
1. 管理ページの「**返納期限アラート**」および「**備品予約一覧**」を確認します。
2. 新規の予約申請（「申請中」）がある場合、内容を確認して「**承認**」ボタンを押します。
3. 貸出日に物品を引き渡したら、「**貸出**」ボタンを押してステータスを「貸出中」にします。
4. 備品が返却されたら、破損や欠品がないか点検し、「**返納確認**」ボタンを押して「返納完了」にします。

> [!IMPORTANT]
> 複数人が同じ備品を同時に予約しても、システムが自動的に在庫数を計算して超過をブロック（排他制御）しているため、二重貸出の心配はありません。

### 2-5. 住民からの意見・相談への対応
1. 管理ページの「**意見交換・相談対応**」セクションを開きます。
2. 住民から届いた投稿内容（清掃要望、街灯の球切れ、防災の相談など）を確認します。
3. 役員会での検討状況に応じて、**対応ステータス**（「検討中」「対応中」「解消」など）を選びます。
4. **返答・対応内容**（例「○月○日に電球交換の手配を行いました」）を入力し、「**返答を保存**」を押します。
5. 保存すると、住民側の「情報交換」画面に即時反映されます。

### 2-6. 回覧板・資料PDFのアップロード
1. 管理ページの「**回覧板・資料アップロード**」を開きます。
2. 保存先（回覧板 / その他資料）を選択し、年度・カテゴリ・タイトルを入力します。
3. 会員限定資料（議事録や総会資料など）の場合は「会員限定」にチェックを入れます。
4. PDFファイルを選択し、「**保存**」を押します。

## 3. よくある質問・トラブル対応

- **Q. パスワード（PIN）を忘れました**
  - 管理者（システム担当役員）に連絡し、認証情報の再発行を依頼してください。
- **Q. 登録した予定を変更・削除したい**
  - 「登録済み町内行事一覧」から対象行事にチェックを入れ、「選択行を修正」または「選択行を削除」を押してください。
- **Q. 画面に変更が反映されません**
  - ブラウザの「再読み込み（更新）」ボタンを押してください。オフラインキャッシュが自動更新されます。
