# システム構成仕様書（無料運用・Firebase+Firestore確定版）

## 1. システム全体概要

本システムは、若松町内会の住民および役員が利用する地域コミュニケーションポータルサイトである。  
**月額0円（完全無料運用）**を前提とし、クレジットカード登録不要の **Firebase Spark プラン**、**Google Drive 無料枠（15GB）**、**GitHub Pages（静的ホスティング）** を組み合わせて構築する。


## 2. 採用アーキテクチャの選定理由と無料運用の根拠

### 2-1. 確定システム構成

| 領域 | 採用技術・サービス | プラン・費用 | 役割と選定理由 |
| :--- | :--- | :--- | :--- |
| **ホスティング** | GitHub Pages | 無料 | 静的ファイルの高速配信。サーバー維持費・管理コストゼロ。 |
| **正本データベース** | Cloud Firestore | Sparkプラン (無料) | 行事、備品、予約、意見、文書メタデータの唯一の正本。トランザクションによる在庫排他制御と高速クエリ。 |
| **認証・アクセス制御** | Firebase Authentication + Security Rules | Sparkプラン (無料) | 会員登録・ログイン、役員権限の厳格な分離。DB層での確実な保護。 |
| **ファイルストレージ** | Google Drive | Google無料枠 (15GB) | 高解像度写真・広報PDFの保存。Firebase SparkではCloud Storageを使用せず、Google Driveに一本化してクレジットカード登録不要の0円運用を担保。 |
| **外部連携・Drive操作** | Google Apps Script (GAS) | 無料 | フロントエンドから Google Drive への安全なファイル受け渡し（トークン検証・非公開ファイルBase64中継）。 |
| **カレンダー描画** | FullCalendar + SWR Cache + Firestore | オープンソース (無料) | 月・週・一覧表示。ゼロ待機枠描画、Docs/events.json による0.05秒先行表示、Firestore期間クエリ、表示時のGAS依存完全排除。 |
| **地域地図** | Google My Maps + Leaflet | 無料 | 地域施設（避難所・集会所・AED）とお散歩コースの表示。 |

### 2-2. 無料運用（月額0円）の成立条件と安全マージン

町内会規模（100〜500世帯、月間アクティブ住民50〜200名）における Spark プラン消費量の試算：

| 項目 | Sparkプラン無料枠（上限） | 若松町内会の想定月間使用量 | 安全マージン（倍率） |
| :--- | :--- | :--- | :---: |
| **Firestore 読み取り** | 50,000 回 / 日 (約150万回/月) | 約 30,000〜50,000 回 / 月 (オフラインキャッシュ併用) | **約 30倍〜50倍** |
| **Firestore 書き込み** | 20,000 回 / 日 (約60万回/月) | 約 300〜1,000 回 / 月 (予約・意見・行事登録) | **約 600倍** |
| **Firestore 保存容量** | 1 GiB | 約 10〜30 MB (テキスト・メタデータ数万件分) | **約 30倍〜100倍** |
| **Firebase Auth** | 50,000 MAU / 月（メール/PW、匿名、Google） | 数十〜数百アカウント | **約 100倍〜500倍** (※SMS認証は有料のため不採用) |
| **Google Drive 容量** | 15 GB / アカウント | 写真・PDF資料 約 2〜5 GB | **約 3倍〜5倍** |
| **GAS 実行枠** | Webアプリ同時実行数 30 / トリガー日計 90分 | 同時アクセス数名〜十数名 / トリガー不使用 | **約 3倍〜10倍** (※トリガーとWebアプリの制限を区別) |
| **GitHub Pages 帯域** | 100 GB / 月 | 約 3〜5 GB / 月 | **約 20倍** |

**運用の結論（条件付き無料運用）**:  
「永続無料保証」や「完全無制限」ではなく、想定利用量（住民50〜200名、月間写真アップロード数十〜百枚、閲覧数数万回）が Spark プランおよび Google 無料枠の制限内にあることで成立する**条件付き無料運用**である。電話番号SMS認証など課金枠を発生させる機能は排除し、Cloud Storage for Firebase を使わず Google Drive に一本化することで、クレジットカード登録なし・月額0円での安定運用を実現する。

## 3. セキュリティと認証情報の管理

1. **秘密鍵の完全隔離**:
   - `FIREBASE_SERVICE_ACCOUNT` は管理用スクリプト（Excelからの初期移行など）でのみ使用し、GitHub Actionsやビルド成果物、公開サイト（`dist/`）には**絶対に含めない**。
2. **公開用 Firebase Config の扱い**:
   - `apiKey`, `authDomain`, `projectId`, `appId` 等は Firebase Web SDK でブラウザに配布される設計（公開前提の値）である。
   - 不正な読み書きは API キーの秘匿ではなく、**Firestore Security Rules** によって完全に防断する。
3. **役員権限の偽装防止**:
   - クライアント側（JavaScript）の表示制御だけでなく、Firestore Security Rules で `get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'officer'` を検証し、役員以外の行事改変・備品設定・承認操作をデータベース層で拒絶する。
