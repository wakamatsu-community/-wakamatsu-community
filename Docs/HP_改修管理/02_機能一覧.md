# 機能一覧・実装状況調査報告書（Firestore構成版）

## 1. 機能ステータス分類基準

- **完成**: 仕様どおり動作し、実運用に耐えうる状態。
- **一部実装**: 基本的なUIやコードはあるが、Firestore連携や詳細機能が未充足の状態。
- **未実装**: 画面または機能が存在しない、あるいは完全に未接続の状態。
- **不具合あり**: 既存のコードにエラー、誤表示、データ不整合、セキュリティ脆弱性がある状態。
- **未検証**: 実環境への接続やルール検証が行われていない状態。

## 3. 解決される既存の重大課題

1. **データベースの完全一元化**:
   - `localStorage` の孤立や Google Sheets との二重管理を廃止し、すべての状態変化を Firestore に集約。登録・更新内容が即時に全端末へ反映される。
2. **ACIDトランザクションによる在庫超過の根絶**:
   - 備品予約に Firestore トランザクションを適用することで、同時予約による在庫超過をサーバーレス環境で100%防止。
3. **カレンダー高速表示と誤表示の撲滅**:
   - 3秒誤表示タイマーを撤去し、FirestoreのIndexedDBローカル永続化キャッシュによって0.1秒台での初期表示を実現。
4. **安全な権限分離**:
   - Firebase Authentication と Firestore Security Rules により、一般閲覧者・会員・役員の権限をデータベース層で確実に防断。
