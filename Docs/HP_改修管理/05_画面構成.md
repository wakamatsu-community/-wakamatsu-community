# 画面構成・UI/UX設計仕様書（Firebase連携版）

## 1. デザイン基本方針

本システムは、若年層から高齢者まで幅広い年齢層の地域住民が日常的に利用する。  
そのため、以下のユニバーサルデザイン原則を徹底する。

- **温かみと落ち着きのある色彩**:
  - ベースカラー: 白・オフホワイト (`#fcfbf8`)
  - メインカラー（町内会のシンボル）: 若松の緑 (`#247246`)
  - アクセントカラー（親しみやすさ）: 温かみのあるオレンジ (`#e67e22`)
  - 警告・注意: 視認性の高い深赤 (`#c0392b`)
- **文字の視認性（アクセシビリティ）**:
  - 本文フォントサイズは 16px 以上（スマホ時 15〜16px）、見出しは 20〜28px。
  - 行間は 1.6〜1.8 を確保し、詰まり感のないゆったりとしたレイアウト。
  - コントラスト比 4.5:1 以上を確保。
- **押しやすいタッチターゲット**:
  - ボタン・リンク・タップ領域は最低 44px x 44px を確保（高齢者のスマホ誤タップ防止）。
- **明確な状態表示**:
  - 「読み込み中」「登録完了」「通信に失敗しました」を大きな文字と明確な色で通知。

## 4. 行事カレンダー画面 (`events.html`) のUI改修詳細

### 4-1. カテゴリ別フィルタUIの追加
カレンダー上部に直感的なフィルタボタン（ピルUI）を設置：
- `すべて`
- `町内行事`（緑バッジ）
- `清掃・美化`（青バッジ）
- `防災・防犯`（赤バッジ）
- `コミニティ・趣味`（オレンジバッジ）

タップで即座にカレンダー上の表示イベントが切り替わる（クライアント側フィルタリングのため0秒反応）。

### 4-2. 表示速度の測定と可視化
カレンダー初期化時に `performance.now()` でロード時間を計測：
- 例: `表示完了: 0.18秒 (オフラインキャッシュ)`
- ユーザーにストレスを与えない高速性を担保。

## 5. 備品予約画面 (`equipment.html`) のUI改修詳細

### 5-1. 4週間空き状況ガントチャートの改善
- 日別セル表示：
  - 緑背景: 空きあり（「残 3台」）
  - 黄背景: 残りわずか（「残 1台」）
  - 赤背景: 在庫ゼロ（「貸出中」）
- 日付タップ操作：
  - 1回目のタップで「貸出日」、2回目のタップで「返納日」を自動セット。
  - 在庫が0の日付は選択不可とし、誤予約をUI側でもブロック。

### 5-2. 複数備品予約カート
- カートリストに追加された備品（例: テントx1、長机x2）を一覧表示し、削除ボタンも設置。
- 送信ボタン押下時、Firestoreトランザクションで一括予約。
