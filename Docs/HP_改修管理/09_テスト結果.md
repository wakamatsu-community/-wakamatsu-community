## 3. 実環境テストとモックテストの区分・検証ステータス

本プロジェクトでは「モック・シミュレータ検証」と「本番外部サービス実環境検証」を厳格に区別して品質管理を実施している。

| 検証領域 | 検証区分 | 実行条件と検証結果 | 実環境接続に向けた残課題 / 必要操作 |
| :--- | :---: | :--- | :--- |
| **JavaScript / UI** | **ローカル実環境** | 全15モジュール構文検査 PASS、静的ビルド PASS、ナビ統一 PASS | GitHub Pages への公開（承認後） |
| **備品予約トランザクション** | **モック検証** | 排他在庫計算・同時並行トランザクション競合・状態遷移テスト 全7ケース PASS | 実Firestoreプロジェクトへの接続テスト（Web APIキー設定後） |
| **Security Rules** | **静的・論理検証** | 役員・会員・未ログインの3権限分離、マスタ改ざん防止ロジック PASS | Firebase Console への `firestore.rules` デプロイ（承認後） |
| **Google Drive / GAS** | **コード・構文検証** | `uploadPhoto_`（トークン検証）、`getSecureDocumentContent_`、`deleteDriveFile_` 構文検査 PASS | 実GAS環境の「ウェブアプリとして導入」再デプロイ（承認後） |
| **Firebase Auth** | **SDK・論理検証** | `firebase-init.js` 初期化・IndexedDB永続化キャッシュ・ログイン状態バッジ連動 PASS | Firebase Console での Email/PW プロバイダ有効化および Webアプリ追加 |
| **カレンダーSWR高速化** | **ローカル実環境** | 3秒誤表示タイマー撤去、静的キャッシュ即時表示（0.05秒）、同期元ステータス通知 PASS | 実Firestore `events` コレクションとの双方向同期検証 |
